# สคริปต์วิดีโอ Demo (3–6 นาที) — SortSense

บันทึกหน้าจอแบบไม่ลิสต์ (unlisted) บน YouTube/Drive แล้วส่งเป็นลิงก์ หรือใช้ Colab/live link ที่รันได้จริงแทนก็ได้

## ช่วงเวลาแนะนำ

**0:00–0:30 — เปิดเรื่อง**
บอกชื่อโปรเจกต์ โจทย์ (ตรวจจับและแยกขยะ 4 ประเภทจากภาพกล้องแบบเรียลไทม์) และทำไมถึงเลือกงานนี้

**0:30–1:30 — สถาปัตยกรรมและการเทรน**
เปิดไดอะแกรม ([report/architecture_diagram.png](architecture_diagram.png)) อธิบายสั้นๆ ว่าใช้ YOLOv8 (CNN detector) fine-tune จาก COCO pretrained บนภาพขยะ 200 ภาพที่เก็บเอง
โชว์เซลล์เทรนใน [kaggle_train_waste_real_v3_hazard_single.ipynb](../kaggle_train_waste_real_v3_hazard_single.ipynb) สักครู่ (ไม่ต้องรอจบ 100 epoch จริง — ตัดต่อ/fast-forward ได้ แต่ต้องบอกผู้ชมตรงๆ ว่าตัดต่อ)

**1:30–3:00 — Demo ใช้งานจริง (success case)**
รัน `web_app.py` เปิดกล้อง webcam ยกขยะ 2–3 ชิ้นที่โมเดลแยกถูก (เช่น ขวดพลาสติก → Recyclable, เศษอาหาร → Organic) ให้เห็นกรอบ bounding box และความมั่นใจ (confidence) ขึ้นจริงแบบเรียลไทม์

**3:00–4:00 — Honest failure case**
ยกวัตถุประเภท Hazardous (เช่น แบตเตอรี่ ของมีคม) ที่โมเดลตรวจพลาด/มั่นใจต่ำ อธิบายตรงๆ ว่าทำไมถึงพลาด (ข้อมูลเทรนน้อยมากในคลาสนี้ — Test มีแค่ 4 ตัวอย่าง) อ้างอิงตัวเลขจริงจากรายงาน (mAP50 Hazardous 58.2%, recall 50%)

**4:00–5:00 — ผลเทียบ baseline**
โชว์ตาราง compare_models.py (YOLOv8n baseline vs YOLOv8m) สรุปว่าโมเดลใหญ่กว่าดีขึ้นแค่ไหน

**5:00–5:30 — ปิดท้าย**
สรุปข้อจำกัดหลัก (ชุดข้อมูลเล็ก) และแนวทางพัฒนาต่อ บอกลิงก์ repo

## หมายเหตุ
- ต้องมีทั้ง success case และ failure case อย่างน้อยอย่างละ 1 กรณี ตามเกณฑ์ Q3
- ถ้าไม่สะดวกอัดกล้องสด ใช้ `detect_realtime.py` หรือรัน inference บนภาพนิ่งจาก Test set ผ่าน notebook แทนได้ ขอแค่เป็น "real input" จริง ไม่ใช่ภาพที่แต่งผลไว้ล่วงหน้า
- พูดบรรยายตลอด (narrated) ตามที่โจทย์กำหนด ไม่ใช่แค่เพลงประกอบ
